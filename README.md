Saif Ali portfolio — logo, favicon and light/dark mode

Upload the contents of this package to the root of the existing GitHub Pages repository. Keep index.html, style.css, script.js and favicon.ico together. Keep the assets folder alongside them; it contains the supplied logo as logo.png (unchanged) and the existing portrait as saif-ali.jpeg (unchanged).

The existing phone, tablet and laptop responsive layouts are retained. The Dark mode / Light mode control remembers its selection in the browser. To update the logo later, replace assets/logo.png with the same filename.
